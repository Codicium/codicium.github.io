# Codicium

Developing extremely simple apps that just work.

I'm dedicated to building minimalist, focused productivity tools for Android and iOS. 

Philosophy centers on creating elegant interfaces that eliminate distractions and help you stay in the flow. 
Software should be intuitive, high-performance, and privacy-respecting by design. 

Currently, I offer **Pomodoro Voice**, a minimalist timer with voice cues, and **Huge Clock**, an ultra-readable full-screen timekeeper. Each app is built with Flutter to ensure a smooth, cross-platform experience. I prioritized visual excellence and essential features over unnecessary complexity. All user data stays on the device, ensuring your privacy is never compromised. The goal is to empower users through simple yet powerful digital tools.
