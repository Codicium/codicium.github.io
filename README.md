# Codicium

Developing extremely simple apps that just work.

Codicium is dedicated to building minimalist, focused productivity tools for Android and iOS. Our philosophy centers on creating elegant interfaces that eliminate distractions and help you stay in the flow. We believe that software should be intuitive, high-performance, and privacy-respecting by design. Currently, we offer **Pomodoro Voice**, a minimalist timer with voice cues, and **Huge Clock**, an ultra-readable full-screen timekeeper. Each app is built with Flutter to ensure a smooth, cross-platform experience. We prioritize visual excellence and essential features over unnecessary complexity. All user data stays on the device, ensuring your privacy is never compromised. Our goal is to empower users through simple yet powerful digital tools.
